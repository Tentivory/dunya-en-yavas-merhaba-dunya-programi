# Dünyanın En Yavaş Merhaba Dünya Programı

Bu program, insanlık tarihinin en önemli problemini çözmek için tasarlanmıştır: **Acelecilik**.

Herkes "Merhaba Dünya" diyor. Ama kimse **gerçekten** merhaba demiyor. Bu program, her harfi 0.8 saniye bekleyerek basar. Çünkü dünya acele etmiyor, sen neden ediyorsun?

## Nasıl Çalışır?

```bash
python merhaba.py
```

Ve izle. Sabırla. Çay iç. Düşün. Ölümsüzlüğü sorgula. Sonra program bitince "vay be" de.

## Özellikler

- Tamamen çalışır (test edildi, gerçekten)
- Hiçbir şey yapmaz ama her şeyi yapar
- ASCII art yok, çünkü o kadar hızlı değiliz
- Gizli bir mesaj içerir (bulamazsın)

## Uyarı

Bu programı çalıştırırken zamanın akışını hissedebilirsiniz. Yan etkiler: Varoluşsal kriz, çay molası isteği, "acaba daha yavaş olabilir mi?" sorusu.
